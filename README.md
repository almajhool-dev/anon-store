# متجر المبرمج المجهول | Anonymous Programmer Store

متجر عربي (RTL) لأدوات Python وتطبيقات Android APK والكورسات والفيديوهات والملفات، بهوية سايبر داكنة، ولوحة مدير كاملة، وحماية متعددة الطبقات.

**الموقع:** https://majhool-store.netlify.app

## البنية (مجانية بالكامل)
| الطبقة | الخدمة | ملاحظات |
|---|---|---|
| الواجهة + CDN | Netlify (Free) | ملفات ثابتة، رؤوس أمان CSP/HSTS |
| الواجهة الخلفية | Neon Functions (Node 24) | 1M استدعاء/شهر |
| قاعدة البيانات | Neon Postgres | RLS، دور مقيّد، 1GB |
| تسجيل الدخول | Neon Auth (Google OAuth) | JWT قصيرة العمر |
| تخزين الملفات | Neon Object Storage (S3) | 5GB، حتى 10GB للملف، رفع مجزأ |

## الميزات
- أقسام: Python، Android APK، الكورسات، الفيديوهات، الملفات والمشاريع، المجانية، المدفوعة، الأحدث، الأكثر تحميلاً
- منتجات مجانية/مدفوعة، خصومات وعروض مؤقتة بعدّاد، إصدارات وتحديثات، تقييمات، مفضلة
- الشراء: طلب برقم مرجعي + تأكيد يدوي من المدير (زين كاش/آسيا حوالة/تحويل)؛ بنية جاهزة لبوابات عراقية (معطّلة حتى التفعيل الرسمي)
- التحميل المدفوع لا يتم إلا بعد التحقق من الشراء في الخادم وقاعدة البيانات، بروابط موقعة مؤقتة
- رفع ملفات ضخمة: مجزأ، متوازي، إيقاف/استكمال، استكمال بعد انقطاع الإنترنت، عرض السرعة والوقت المتبقي، دون ضغط
- كورسات بدروس، مشغل يحفظ آخر موضع وسرعة التشغيل، دروس مجانية للمعاينة
- لوحة مدير: إحصاءات، منتجات، طلبات، مستخدمون (حظر/صلاحيات)، رسائل، إشعارات، تخزين، المظهر (ألوان/خطوط/خلفيات/شعار/أيقونة/أقسام/تسجيل/متجر)، أمان، سجل عمليات غير قابل للحذف

## الأمان
RLS على كل الجداول، دور قاعدة بيانات مقيّد، تحقق JWT (EdDSA)، CORS بقائمة سماح، كشف SQLi/XSS/Traversal/RCE، رصد أدوات الفحص، مصيدة مسارات (`/wp-admin`، `/.env`...)، حظر تلقائي متصاعد مع فك الحظر من اللوحة، تنبيهات للمدير، فحص بصمة الملفات المرفوعة، CSP صارمة، روابط موقعة. لا يوجد نظام محصّن 100%.

## التطوير المحلي
```bash
npm ci
cp .env.example .env.local   # املأ القيم
npm run db:migrate
node scripts/dev-api.mjs     # API على 8787
VITE_API_URL=http://localhost:8787 npm run dev
```

## النشر
- **الواجهة:** اربط المستودع في Netlify (Site configuration → Build & deploy → Link repository) فيُنشر تلقائياً مع كل دفع إلى `main` (يقرأ `netlify.toml`).
- **الـ API:** `npm run build:api && node scripts/publish-api.mjs` ثم حدّث متغيرَي `API_CODE_URL` و`API_CODE_SHA256` للدالة `api` في Neon.

## حدود الخطط المجانية
- Netlify Free: 300 رصيد/شهر (يُستهلك بالنشر والزيارات)؛ عند النفاد يتوقف الموقع حتى بداية الشهر التالي.
- Neon Free: 100 ساعة حوسبة/مشروع، 1GB قاعدة بيانات، 5GB تخزين، 5GB نقل بيانات خارجي/شهر (يشمل التحميلات والفيديو)، تتوقف الحوسبة عند الخمول وتعود تلقائياً.
- للتحميلات الكثيفة: يُنصح بإضافة Cloudflare R2 (تخزين 10GB مجاني بلا رسوم نقل).
